# Couple photos (Scene 5)

Drop files here — no code changes needed:

| File                                     | Used for                         | Tips                                          |
| ---------------------------------------- | -------------------------------- | --------------------------------------------- |
| `hero.webp` (or `.jpg`, `.png`, `.avif`) | The arched hero frame            | Portrait 4:5, ≥ 1200 px tall, subject centred |
| `gallery-01.jpg`, `gallery-02.webp`, …   | The "Moments" gallery + lightbox | Any aspect, ≤ 1600 px long edge, WebP ~80     |

- Gallery photos are shown in file-name order; when at least one exists, the six
  illustrated placeholders disappear.
- `illustration.svg` is the placeholder couple (generated by
  `tools/placeholder-art/couple.mjs`); it is only shown while `hero.*` is missing.
- Captions for real photos default to "Moment 1, 2, …" — edit them in
  `src/scenes/couple/photos.ts`.
